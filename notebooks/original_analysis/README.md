# Original analysis archive

These files are unmodified snapshots from the study's `02_analysis_code` Google Drive folder. They preserve the Colab-era analysis record and are not the maintained public execution path.

Some notebooks and helper scripts contain intermediate or superseded text, absolute Colab paths, and frozen-run assumptions. In particular, do not treat prose inside `build_si.py` as the current manuscript statement. The current manuscript uses the shared-hour IRA comparison with 17 lower-interval and 9 upper-interval H-preserved/Y-reversed pairs; representation-specific support is a sensitivity calculation.

For reproduction, use `../../src/dac_equilibrium/`, `../../scripts/`, and `../reproduce_manuscript.ipynb`.
